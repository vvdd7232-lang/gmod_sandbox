# GodotMod Sandbox

Физическая песочница в стиле Garry's Mod на Godot 4.3.

## Запуск

1. Открой проект в **Godot 4.3** (папка с `project.godot`).
2. Дождись импорта ресурсов при первом открытии (текстуры `assets/*.jpg`).
3. Запусти главную сцену `scenes/main.tscn` (F5).

## Управление

- **WASD** — движение, **Shift** — спринт, **Пробел** — прыжок
- **Мышь** — обзор, **ЛКМ/ПКМ** — действие оружия
- **1 / 2 / 3** или **колесо мыши** — смена оружия (Physgun / Toolgun / Gravity Gun)
- **E** (при захвате физиганом) — вращение объекта
- **Q** — меню спавна предметов и инструментов
- **R** — сброс/разморозка захваченного объекта, **Shift+R** — очистить все пропы

## Процедурные текстуры

Текстуры в `assets/` сгенерированы скриптом `tools/make_textures.sh`
(ImageMagick). Для перегенерации: `bash tools/make_textures.sh`.
